## Décisions de périmètre Phase 1 (tranchées par l'audit)

| Décision                                  | Choix P1                                                        | Justification                                                                                                                                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Chemin browser-burn (ffmpeg.wasm client)  | **ABANDONNÉ P1** — serveur uniquement                           | 2 chemins = 2× la surface de test ; le cron serveur est le chemin nominal prouvé ; supprime `@ffmpeg/ffmpeg`, `@ffmpeg/util`, les headers COEP et la route `finalize`                                                |
| Brand kits (logos/fonts Agency)           | **ABANDONNÉ P1** — réintroduction P3 si tier studio le justifie | Couplage fort storage+UI pour une feature de tier supérieur absent du pricing P1                                                                                                                                     |
| Résolutions 2K/4K                         | **ABANDONNÉ P1** — 1080p mono-tier                              | Gating par plan = P3 ; simplifie quotas et `RESOLUTION_TIER_SCALE`                                                                                                                                                   |
| Sources **audio** (podcast = mp3/m4a/wav) | **NOUVEAU module audiogramme**                                  | ClipFlow suppose une source vidéo (burn sur frames). Un podcast est audio : il faut générer un fond (couleur/waveform ffmpeg `lavfi`) puis burn les sous-titres dessus. N'existe pas dans VidiaFlow — à écrire (S/M) |
| Transcription                             | **Découper le segment AVANT Whisper**                           | VidiaFlow transcrit la source puis découpe. Sur épisode 2-3h : dépasse ~25 MB/appel Whisper. P1 : `ffmpeg -ss/-to` extrait le segment, puis transcription du segment seul                                            |
| Traduction cues (Claude Haiku)            | **CONSERVÉE** (option langue cible ≠ source)                    | Déjà agnostique ; prépare le terrain P2                                                                                                                                                                              |
| Disclosure AI Act (audit log)             | **CONSERVÉE et renforcée**                                      | Trust moat PolyCast ; le `logDisclosure()` best-effort de VidiaFlow devient bloquant-en-log (alerte si échec)                                                                                                        |

**Indexes** (copiés du pattern VidiaFlow consolidé) :

- `jobs` : `(status, created_at) WHERE status IN ('pending','processing')` (claim) ; `(status, attempt_count) WHERE status='pending'` (retry) ; `(user_id, created_at DESC)`
- `clips` : `(user_id, status, created_at DESC)` ; `(episode_id)` ; `(video_storage_path) WHERE video_storage_path IS NOT NULL` (lifecycle)
- `episodes` : `(user_id, created_at DESC)`

**RPCs SECURITY DEFINER (service_role)** — copies adaptées de `20260512010_quota_atomic_rpcs.sql` :

- `clips_reserve_quota(p_user_id, p_seconds, p_limit)` — réservation atomique au gate (UPDATE…WHERE…RETURNING, pas de fenêtre de course gate→job)
- `clips_refund_quota(p_user_id, p_seconds)` — refund sur échec job (appelé par le cron)
- `reset_clip_quotas_due()` — reset mensuel (cron)

**Realtime** : publication `supabase_realtime` sur `clips` + `REPLICA IDENTITY FULL` (le hook UI s'abonne à `UPDATE … id=eq.{clipId}`). RLS = couche d'auth des subscriptions.

## 7. Risques & dette

| Risque                                                                                   | Sévérité | Mitigation                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fonts libass absentes sur lambda Linux** → MP4 rendu SANS sous-titres, silencieusement | P0       | `outputFileTracingIncludes` sur les routes burn + `fonts/Inter.ttf` embarquée ; test d'intégration "le MP4 contient des sous-titres" (diff de frames) avant GA ; audit fonts par style (certains styles référencent Bebas/Anton non embarquées chez VidiaFlow → fallback Inter) |
| **Whisper 25 MB max / épisodes podcast 2-3h**                                            | P0       | Découpe du segment AVANT transcription (`ffmpeg -ss/-to`) — P1 ne transcrit jamais l'épisode entier. La transcription full-episode (P2 dubbing) exigera un chunking 10-15 min avec merge de timestamps                                                                          |
| **Source audio sans piste vidéo** → burn impossible tel quel                             | P0       | Nouveau module `render-audiogram.ts` (fond lavfi/waveform) branché dans `run-job` quand `mp4-probe` ne détecte pas de piste vidéo                                                                                                                                               |
| **maxDuration Vercel 300s** vs render long (nominal ~70s pour clip 30s, p99 ~180s)       | P1       | Clips bornés ≤ 180s en P1 (validation Zod) ; stuck-recovery cron (450s) + retry_count=1 ; envisager worker dédié en P4 (déjà roadmappé)                                                                                                                                         |
| **SSRF sur download source URL**                                                         | P1       | Porter `validate-outbound-url` (blocklist IP privées/link-local) + compléter ranges IPv6 (`fc00::/7`) et RFC 6598 — noté incomplet par l'audit                                                                                                                                  |
| **Course quota gate→job** (réservation non atomique)                                     | P1       | RPCs atomiques `clips_reserve_quota`/`clips_refund_quota` dès la création (pattern VidiaFlow 20260512010) ; refund loggé, alerte si l'RPC échoue                                                                                                                                |
| **Watermark contournable si `profiles.plan` modifiable par l'user**                      | P1       | RLS UPDATE de profiles ne doit jamais exposer `plan` (colonne posée en P3 ; à verrouiller dans la migration P3)                                                                                                                                                                 |
| **Pointeurs DB → fichiers storage supprimés par lifecycle**                              | P2       | Reprendre le pattern 20260513220 : le cleanup NULL les colonnes URL/path dans la même opération                                                                                                                                                                                 |
| **Groq rate-limit / SLA**                                                                | P2       | Fallback OpenAI automatique sur 429 + kill-switch env ; logger coût par job (`cost_usd`)                                                                                                                                                                                        |
| **Signed URLs 24h expirées en galerie**                                                  | P2       | `refresh-urls.ts` au render server (pattern VidiaFlow `refreshThumbnailUrls`)                                                                                                                                                                                                   |
| **Realtime flake (mobile/3G)**                                                           | P2       | Conserver le polling fallback du hook (cap 6 min) + toast "rendering en cours"                                                                                                                                                                                                  |
| **Scripts non-latins en tofu** (CJK/AR/RU sans font dédiée)                              | P2       | `detectScriptFont()` porté ; si langues CJK/AR vendues GA → embarquer Noto subset correspondant (poids à arbitrer)                                                                                                                                                              |
| **Egress storage 3× par job** (download whisper + download ffmpeg + upload output)       | P3       | Accepté P1 (déjà le cas VidiaFlow) ; buffering /tmp unique réutilisé entre étapes (déjà le pattern run-job)                                                                                                                                                                     |
| **Dérive doc/code sur smart-crop** (sharp vs @remotion/probe)                            | P3       | Trancher au port : lire le fichier réel, garder sharp, ne pas installer Remotion                                                                                                                                                                                                |
